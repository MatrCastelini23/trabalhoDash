# Trabalho DashBoard NextJS versão 16

## Proposta: 

A proposta do trabalho é fazer duas páginas utilizando a navegação do NextJS. 
- Tela de Login.
- Tela de DashBoard com link para uma listagem de produtos.

## Minha ideia:

Fazer uma tela de administração de produtos. Ao fazer login o usuário é redirecionado para uma lista de produtos cadastrados. <br> Um a mais vai ser a possibilidade de criar, atualizar e deletar produtos.
